# 🎓 KIT Helping Hand — Academic Resource Platform
### *Centralized Institutional Knowledge Vault for Khanpur Institute of Technology (KIT), Pakistan*

## 🚀 LinkedIn Post Copy (Ready to Copy & Paste)

```markdown
🚀 Excited to unveil my latest full-stack project: KIT Helping Hand — a centralized academic resource platform engineered for Khanpur Institute of Technology (KIT), Pakistan! 🎓✨

In many universities, students face the perennial struggle of scattered course materials across WhatsApp groups, broken Drive links, and missing past papers right before midterm and final exams. 

To solve this, I designed and built KIT Helping Hand — a production-grade institutional repository that centralizes lecture notes, university exam papers (PU / UET), lab assignments, and study materials into one secure, lightning-fast digital campus portal.

🌟 Key Engineering Highlights & Capabilities:

✅ Universal Document Vault: High-speed browsing, filtering, and previewing for any academic format (PDFs, DOCX, PPTX, Images, ZIP archives).
✅ Past Exam Archives: Filtered categorization for Solved Answer Keys vs. Unsolved practice papers across semesters and degree programs.
✅ Integrated In-Browser PDF/Doc Viewer: Custom modal with zoom, pan, full-screen inspection, and secure direct downloads.
✅ Institutional Role-Based Access Control (RBAC):
   • Students: Personalized resource discovery & request submission.
   • CR / GR (Class Representatives): Verified Content Manager permissions to upload lecture handouts for their classes.
   • Super Admin: Complete governance over academic programs, admission batches, user privileges, and audit logs.
✅ Two-Way Academic Inquiry Desk: Students can submit inquiries for missing lecture notes or syllabus files and receive direct faculty/admin feedback.
✅ Production-Grade Architecture: Restrained institutional UI/UX aligned with KIT’s brand identity, responsive drawer navigation, and robust security middleware.

🛠️ Tech Stack:
• Frontend: React 18, TypeScript, Tailwind CSS, Lucide Icons, Vite
• Backend: Node.js, Express.js, TypeScript, RESTful API Architecture
• Database & ORM: PostgreSQL / SQLite with Prisma ORM (Strict relational schema)
• Security: JWT session authentication, Argon2/Bcrypt password hashing, Helmet headers, rate limiting, and private storage file vault

💡 Why this project matters:
This isn't just a static template; it's a fully normalized, secure, and production-tested university solution designed to be presented to institutional leadership and scaled across academic departments.
```
